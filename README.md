# Quran Memorization Tracker

Quran Memorization Tracker is a simple Django web application that helps people organize and follow their Quran memorization progress.

## Project Pages

- Home page
- Surahs list page
- Memorization progress page
- Add memorization entry page

## Features

- Simple navigation between pages
- Surahs list with memorization status
- Progress overview
- Form page for adding a memorization entry

## Technologies Used

- Python
- Django
- HTML
- CSS

## How to Run the Project

```bash
python manage.py runserver
